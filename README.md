# Pearlcrest Dental Clinic

Premium dental website for Pearlcrest Dental Clinic — Hor Al Anz East, Dubai, UAE.

Multilingual (Arabic, English, French) with RTL support for Arabic.

## Development

```bash
npm install
npm run dev
```

## Scripts

- `npm run build` — production build
- `npm run lint` — ESLint
- `npm run type-check` — TypeScript

## Environment

Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_SITE_URL`.
